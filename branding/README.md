# AurevonLabs brand assets

`aurevonlabs-logo.jpg` — the official Aurevon Labs logo (supplied by Mike, 2026-08-31).
Treat this file as the canonical reference for the parent-company mark.

**What it looks like**

- Mark: an angular capital-A monogram built from two strokes. The left stroke is a
  blue gradient (bright azure at the top falling to a deep royal blue at the base);
  the right stroke is white fading to pale silver-blue. The crossbar is implied by
  the negative space between the strokes.
- Wordmark: `AUREVON` in a bold white geometric sans, all caps; `LABS` beneath it in
  a cool gray, all caps, with wide letter-spacing.
- Ground: near-black navy.

**How it relates to Cohive**

Cohive deliberately carries its own consumer identity — dark navy `#0A0F1C` with
honey amber `#F5A524` and the hexagon mark — with only a small "by AurevonLabs"
credit line (a decision locked in during the original design sessions). Use this
logo for parent-company contexts: About screens, legal/footer marks, the app store
developer listing, pitch material. Do not restyle the app toward the logo's blue.
